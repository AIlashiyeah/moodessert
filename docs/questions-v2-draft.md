# Moodessert 题库 v2（16 型，中文）

规则：先选 MBTI（必选、完全信任）→ 该型专属 5 题 → 落到这块甜点的 4 个分支之一。选项写“脑内独白”，每套最多 1 个反转。
括号里是隐藏分支，不显示给用户。
命名原则：分支名和夸奖只用这个型自我认同的词（ENTP=求真、ISTJ=可靠、ESFP=活在当下），外人吐槽它的词只能放在“虽然”后半句里，而且要说得像在夸。

## ENTP · 提拉米苏

**分支**
- 酒香经典 · 求真系：虽然总有人说你爱抬杠，但你追的从来不是输赢，是那个没人愿意挖到底的真相。
- 草莓 · 灵感喷泉系：虽然你的草稿箱比发出去的还多，但你随手一句，就是别人想半天想不出的梗。
- 焙茶 · 系统拆解系：虽然别人总说你想太多，但你只是比所有人早一步看到了第三步。
- 辣椒巧克力 · 规则测试系：虽然你总忍不住去戳一下规则，但很多规则，正是被你戳出漏洞才变得更好。

**1. 你被困在宜家样板间迷宫两小时**
- A 小红书草稿已经打好：《被宜家困住两小时，我悟了》，九宫格都选好了（草莓）
- B 开始算账：按时薪亏了多少、错过了哪几单外卖，再按刚才那杯水推算几点会尿急（焙茶）
- C 立刻打给朋友吐槽，挂电话时已经从宜家骂到了人类城市规划（酒香）
- D 偷偷把鼻屎抹在样板间沙发底下（辣椒巧克力）

**2. 群里有人认真转发：“金鱼只有 7 秒记忆”**
- A 查到原始出处，顺便挖出这句话最早是哪个营销号编的（酒香）
- B 截图转发到另一个群：“这个群有人信这个”（草莓）
- C 开始想：如果真的只有 7 秒，鱼缸里每天都是新世界，那它是不是比我幸福（焙茶）
- D 不纠正，顺着编一条更离谱的，数数有几个人信（辣椒巧克力）

**3. 电梯突然停了，一直不动，灯也灭了** ← 反转题
- A 打开手电筒，先给自己录一条：“电梯停了第 0 分钟，留个记录”（草莓）
- B 按人数和轿厢大小推算氧气还能撑多久，算完发现其实够，有点失望（焙茶）
- C 跟同梯陌生人争论：现在该先按警铃还是先打电话（酒香）
- D 把所有按钮按一遍，包括那个不知道干嘛的钥匙孔（辣椒巧克力）
- 反转：其实你只是没按楼层，电梯灯省电休眠了。

**4. 凌晨两点，你在**
- A 在评论区追问一个说法的出处，追到对方答不上来、把你拉黑（酒香）
- B 录一条“凌晨两点的我”口播，准备明天发（草莓）
- C 规划一个永远不会做的创业项目，logo 都想好了（焙茶）
- D 在家族群发一个只有 emoji 的谜语，等明早看谁先破解（辣椒巧克力）

**5. 被拉去听一场超无聊的讲座**
- A 连环举手，一个问完接下一个，问到讲者开始翻自己的 PPT 找答案（酒香）
- B 偷偷录了几段，回家剪成一条锐评视频（草莓）
- C 五分钟摸清套路，开始小声给同伴预告讲者下一句，说中了就补一句“你看，我就说吧”（焙茶）
- D 听了十分钟，判断不值得，直接起身离场（辣椒巧克力）

## INFJ · 法式千层

**分支**
- 香草 · 洞察系：虽然你总能一眼看穿别人，但你从来只把看穿用来体谅。
- 伯爵茶 · 意义追寻系：虽然你半夜的问题没人答得上来，但正是这些问题，让你活得比别人深一层。
- 覆盆子 · 暗中守护系：虽然你永远先想到别人，但被你照顾过的人，都悄悄把你放在了第一位。
- 焦糖 · 内在宇宙系：虽然你心里的千层波澜别人看不见，但你看世界的那份细腻，没人复制得来。

**1. 聚会上有人讲了一个冷场的笑话**
- A 在他尴尬的 0.5 秒里笑出声，救场（覆盆子）
- B 你已经看出来，他今晚讲冷笑话是因为工作不顺（香草）
- C 表面微笑，心里已经替这个笑话写好三个更好的结尾（焦糖）
- D 开始想：人为什么需要别人笑，才觉得自己安全（伯爵茶）

**2. 你发了一大段，对方只回了一个“哦”**
- A 把聊天记录往上翻，逐句排查自己哪里说错了（焦糖）
- B 从这个“哦”的发送时间，推断出他此刻在开会（香草）
- C 判断他大概很累，顺手给他点了一杯咖啡外卖（覆盆子）
- D 开始想：一千年后，人类会不会只剩一个字交流（伯爵茶）

**3. 门口出现一个快递，收件人是你，但你什么都没买** ← 反转题
- A 越想越感动：一定是某个默默在乎你的人（焦糖）
- B 研究胶带的缠法，推断寄件人的性格（香草）
- C 先不拆，怕是别人寄错了，等对方来拿（覆盆子）
- D 思考：一份没有署名的礼物，是送给你，还是送给“被惦记”这件事（伯爵茶）
- 反转：其实是你三个月前半夜下单、自己忘了的东西。

**4. 凌晨两点，你在**
- A 备忘录里写一段永远不会发出去的长文（焦糖）
- B 回想今天每个人的表情，给他们分别配上 BGM（香草）
- C 给明天考试的朋友写一句“你会好的”，定时早上 7 点发（覆盆子）
- D 盯着天花板，第三十七次想“我到底是谁”（伯爵茶）

**5. 有人在你面前突然哭了**
- A 什么都不问，递纸巾，陪他坐到他想说为止（覆盆子）
- B 你比他自己更早知道他为什么哭（香草）
- C 跟着一起难过，回家路上还在替他想台词（焦糖）
- D 开始想：眼泪到底是流给自己的，还是流给别人看的（伯爵茶）

## ISTJ · 纽约芝士蛋糕

**分支**
- 原味 · 可靠系：虽然你的原则多到别人记不住，但大家心里都清楚，跟着你走永远不会出错。
- 蓝莓 · 万全准备系：虽然你的备忘录比别人的日记还长，但每次出状况，掏出解决办法的总是你。
- 海盐焦糖 · 行动派温柔系：虽然你嘴上一句软话都没有，但你做的每件事都比软话更暖。
- 抹茶 · 匠心系：虽然你一件事能死磕到凌晨，但你交出去的东西，从来不用别人再改一遍。

**1. 拼好的家具，少了一颗螺丝**
- A 拍照标注，发邮件给客服，附上订单号和说明书页码（原味）
- B 去五金店买一颗一样的，顺便把家里所有螺丝分类装盒（蓝莓）
- C 骂了一句，然后顺手帮邻居也检查了一遍他们的家具（海盐焦糖）
- D 嘴上说算了，凌晨一点还在研究替代方案（抹茶）

**2. 朋友说：“随便找家店吃吧”**
- A “随便”是不存在的，去上次那家（原味）
- B 三家备选已发群里，附人均、评分和排队时间（蓝莓）
- C 回了句“都行”，然后默默订好了位（海盐焦糖）
- D 研究了四十分钟点评，最后还是去了上次那家（抹茶）

**3. 地铁停在隧道里不动了，广播也没声音** ← 反转题
- A 看表开始计时，以防之后要写投诉（原味）
- B 检查包里：水、充电宝、纸巾都在，安心了（蓝莓）
- C 对旁边一脸紧张的阿姨说“慌什么”，然后把座位让给她（海盐焦糖）
- D 继续做今天的待办，没信号就离线做（抹茶）
- 反转：其实只是在等前车出站，二十秒后就开了。

**4. 凌晨两点，你在**
- A 睡觉。凌晨两点就该睡觉（原味）
- B 起夜，顺手把冰箱里过期的东西清掉了（蓝莓）
- C 想白天那句话是不是说重了，决定明天找机会补一句（海盐焦糖）
- D 还在调表格格式，就差一条边框就完美了（抹茶）

**5. 有人插队，就插在你前面**
- A 礼貌但大声：“后面排队哦。”（原味）
- B 默默记下时间、地点和他衣服的颜色（蓝莓）
- C 心里骂了三遍，看到他抱着小孩，让他先了（海盐焦糖）
- D 不说话，往前站一步，用身体让他明白（抹茶）

## ESFP · 芒果绵绵冰

**分支**
- 芒果原味 · 气氛担当系：虽然你一出现场子就吵起来了，但没有你的局，大家连照片都不想拍。
- 草莓炼乳 · 活在当下系：虽然你想一出是一出，朋友的心脏有点受不了，但他们最难忘的回忆里全都有你。
- 西瓜 · 快乐制造机系：虽然你总把最好玩的位置让给别人，但大家记得最清楚的，偏偏是你。
- 跳跳糖 · 体验收集家系：虽然你的兴趣换得比谁都快，但你尝过的人生滋味，也比谁都多。

**1. KTV 里没人敢点第一首**
- A 抢过麦，点一首全场都会的，第一句就站上沙发（芒果）
- B 点一首谁都没听过的小语种歌，硬唱到底（草莓炼乳）
- C 把麦塞给最害羞的那个，然后陪他一起唱（西瓜）
- D 一口气点了十首，唱两句就跑去研究点歌机的灯光模式（跳跳糖）

**2. 突然下大雨，你被困在便利店门口**
- A 跟店员和其他躲雨的人组成临时小团体，开始下注雨几点停（芒果）
- B 直接冲进雨里：就当免费淋浴（草莓炼乳）
- C 把伞借给赶时间的陌生人，自己继续等（西瓜）
- D 买了一支冰淇淋，吃到一半雨停了，又买了一支（跳跳糖）

**3. 逛商场，突然所有灯一起熄灭，音乐也停了** ← 反转题
- A 第一个尖叫，然后带头笑（芒果）
- B 打开手机闪光灯，当场开起演唱会（草莓炼乳）
- C 先确认身边的朋友都在（西瓜）
- D 拍一张全黑的照片发朋友圈：“猜我在哪”（跳跳糖）
- 反转：其实是商场在准备生日惊喜，蛋糕已经推出来了，不是给你的。

**4. 凌晨两点，你在**
- A 还在外面，刚认识的朋友说要去吃第三摊（芒果）
- B 临时决定打车去海边等日出（草莓炼乳）
- C 跟心情不好的朋友视频，逗到他笑出鼻涕泡（西瓜）
- D 打开购物车，关上，又打开（跳跳糖）

**5. 有人送了你一盆植物**
- A 给它起名字，周末带它一起去聚会（芒果）
- B 第二天就把它搬到阳台最晒的地方：带它见见世面（草莓炼乳）
- C 每天跟它说早安，比对自己还上心（西瓜）
- D 前三天天天浇水，第四天开始忘了它的存在（跳跳糖）

## INTJ · 黑巧克力挞

**分支**
- 海盐 · 战略系：虽然你计划好的事很少告诉别人，但等别人反应过来，你已经走到终点了。
- 橙皮 · 远见系：虽然大家常听不懂你在担心什么，但三个月后，他们都会回来说“你当时说对了”。
- 咖啡 · 独立系：虽然你常被说不合群，但你一个人做成的事，往往比一群人开会还多。
- 覆盆子 · 高标准系：虽然你对什么都挑剔，但被你认可过的东西，从来经得起时间。

**1. 小组作业第一次开会，四十分钟还没进入正题**
- A 脑子里已经把整个项目拆完了，只是在等合适的时机开口（海盐）
- B 默默预测这组会在第几周崩，提前做好了备份方案（橙皮）
- C 说一句“这部分我来”，回家自己做完了一半（咖啡）
- D 盯着别人 PPT 里对不齐的字体，忍了很久（覆盆子）

**2. 朋友兴奋地拉你一起抽网红盲盒**
- A 先算一下：抽中隐藏款的期望花费是多少（海盐）
- B 判断这个 IP 半年后就没人记得，礼貌拒绝（橙皮）
- C “你抽吧，我看着”，然后看了一下午（咖啡）
- D 拿起来看了一眼做工，放回去了（覆盆子）

**3. 半夜手机弹出：“您的账户在异地登录”** ← 反转题
- A 冷静三步：改密码、查记录、开二次验证（海盐）
- B 顺手把所有账号的密码全换了，以防下一次（橙皮）
- C 不惊动任何人，自己一晚上查清楚（咖啡）
- D 顺便发现这家公司的安全设计很烂，写了一份改进建议（覆盆子）
- 反转：其实是你自己平板上的旧登录，系统刚刚才反应过来。

**4. 有人问你：“五年后想做什么？”**
- A 给出一份五年计划，精确到每年第几季度（海盐）
- B 反问：五年后这个行业还在不在（橙皮）
- C “我自己会知道的。”（咖啡）
- D 心里想：问这个问题的人，自己大概还没想清楚（覆盆子）

**5. 凌晨两点，你在**
- A 第四次修改人生计划表（海盐）
- B 读一篇讲十年后世界的长文，读完觉得大家都太乐观了（橙皮）
- C 一个人把一件拖了三天的事做完了（咖啡）
- D 重写一封邮件的第一句话，第七稿（覆盆子）

## ENTJ · 歌剧院蛋糕

**分支**
- 经典咖啡 · 统帅系：虽然你一开口大家就自动开始分工，但正是有你，事情才真的会被做完。
- 抹茶 · 破局系：虽然你总嫌事情推进太慢，但每次卡死的局面，都是你一句话打开的。
- 覆盆子 · 野心系：虽然你的目标总让人觉得太大，但你说过的事，后来大多都成了真。
- 伯爵茶 · 体系搭建系：虽然你连旅行都要做成项目，但跟你出门的人，从来没踩过坑。

**1. 朋友聚餐，讨论了半小时去哪吃**
- A 直接拍板：“这家，七点，我订位。”（经典咖啡）
- B 列两个选项，限时一分钟投票（抹茶）
- C 选了一家最难订的，并且订到了（覆盆子）
- D 顺便提议每月固定聚一次，下次谁组织你已经排好了（伯爵茶）

**2. 小组作业有人一直不回消息**
- A 当场重新分工，他那部分你接了，再在群里说清楚（经典咖啡）
- B 直接打电话过去，五分钟内拿到一个明确的交付时间（抹茶）
- C 顺手把这次作业做成了能写进简历的项目（覆盆子）
- D 建了一张进度表，所有人的状态一目了然（伯爵茶）

**3. 学校突然停电，所有人围在走廊发呆** ← 反转题
- A 已经在安排：谁去找物业，谁去看电梯里有没有人（经典咖啡）
- B 打给物业问到恢复时间，宣布“十分钟后回来继续”（抹茶）
- C 带大家去楼下咖啡厅开会，效率反而更高了（覆盆子）
- D 把今天剩下的事按“需不需要电”重新排了一遍（伯爵茶）
- 反转：其实只是这一层的保险丝跳了，物业三分钟就合上了。

**4. 玩桌游，大家都说只是随便玩玩**
- A 三轮之后，你在指挥全桌的走法（经典咖啡）
- B 发现一个规则漏洞，一回合结束游戏（抹茶）
- C “随便玩玩”是不存在的。你赢了（覆盆子）
- D 已经在研究最优策略，下次带攻略来（伯爵茶）

**5. 凌晨两点，你在**
- A 回完明天要发的所有消息，排好定时发送（经典咖啡）
- B 终于想通了卡了一周的那个问题，马上写下来（抹茶）
- C 看某个创始人的访谈，看完把五年目标又往上调了一档（覆盆子）
- D 搭一套新的 Notion 系统，用来管理你的整个人生（伯爵茶）

## INTP · 咖啡冻

**分支**
- 原味黑咖 · 本质追问系：虽然你问“为什么”能问到别人想跑，但你理解一件事，是真的理解到了底。
- 炼乳 · 脑洞宇宙系：虽然你的脑子一天开五十个窗口，但随便一个，都比别人的整套想法有意思。
- 椰奶 · 精确系：虽然你常为一个用词纠正别人，但你说出口的话，几乎找不到漏洞。
- 焦糖 · 深潜系：虽然你的兴趣冷门到没人能聊，但你在那个领域知道的，比大部分人一辈子都多。

**1. 有人说：“这个道理大家都懂。”**
- A 追问：具体是哪个道理，懂到什么程度（原味黑咖）
- B 开始想：如果大家都懂，为什么还要说出来（炼乳）
- C 纠正：“大家”这个范围太大了，样本是多少（椰奶）
- D 想起一个相关的冷知识，讲了二十分钟（焦糖）

**2. 你本来要回一条消息**

- A 发现一个设计缺陷，自己想办法绕了过去（经典）
- B 用了一周，开始研究怎么改装它（咖啡）
- C 带着它去了一个没人去过的地方测试（椰奶）
- D 说明书没看，十分钟就会用了（海盐）

**5. 凌晨两点，你在**
- A 修好了白天困扰全组的那个 bug，没告诉任何人（经典）
- B 拆一个旧耳机，只是想看看里面长什么样（咖啡）
- C 一个人骑车去吃夜宵（椰奶）
- D 睡觉。睡不着就看会儿天花板，也挺好（海盐）

## ISFP · 马卡龙

**分支**
- 玫瑰 · 审美系：虽然你挑东西挑到朋友想走，但你挑中的，从来没出过错。
- 薰衣草 · 安静自我系：虽然你常常需要一个人待着，但你独处时攒下的温柔，最后都给了身边的人。
- 开心果 · 感官系：虽然你会为了一块好吃的甜点绕半个城，但你过的每一天，都比别人多一点滋味。
- 柚子 · 随心系：虽然你常常临时改主意，但你跟着心走的样子，比任何计划都好看。

**1. 你走进一家咖啡店**
- A 先看灯光和杯子好不好看，再决定点什么（玫瑰）
- B 挑了角落最安静的位置，坐了一整个下午（薰衣草）
- C 点了菜单上最奇怪的那款，喝一口就爱上了（开心果）
- D 本来是去喝咖啡的，最后买了店里的一个杯子走了（柚子）

**2. 朋友让你帮忙挑衣服**
- A 一眼挑中最适合他的那件，他自己都没想到（玫瑰）
- B 陪他逛，心里在想晚上回家画什么（薰衣草）
- C 摸了一下面料：“这件穿起来会很舒服。”（开心果）
- D 逛到最后，你自己买了三件（柚子）

**3. 你常去的那家小店突然关门了，门上什么都没贴** ← 反转题
- A 拍了一张关着门的照片，意外地好看（玫瑰）
- B 难过了一整天，像失去了一个秘密基地（薰衣草）
- C 回想起那家店的每一个角落、每一种味道（开心果）
- D 随便走走，又发现了一家新的小店（柚子）
- 反转：其实老板只是去旅行了，下周就回来。

**4. 你的房间**
- A 每样东西都是挑过的，连插座都是好看的（玫瑰）
- B 有一个只属于你的角落，谁都不能碰（薰衣草）
- C 香薰、毯子、暖光，躺下去就不想起来（开心果）
- D 每个月都按心情重新摆一次（柚子）

**5. 凌晨两点，你在**
- A 改一张照片的调色，改到第十二版（玫瑰）
- B 一个人戴着耳机，在房间里慢慢跳舞（薰衣草）
- C 泡一杯热巧克力，坐在窗边看夜景（开心果）
- D 突然想剪头发，第二天真的去剪了（柚子）

## ESTP · 巴斯克芝士

**分支**
- 原味焦香 · 行动系：虽然你总是先冲再想，但等别人想好的时候，你已经做完回来了。
- 开心果 · 冒险系：虽然你干过的事让朋友心惊胆战，但他们最爱讲的故事，主角都是你。
- 抹茶 · 临场反应系：虽然你从不提前准备，但每次临场，你都是全场反应最快的那一个。
- 黑巧 · 现实主义系：虽然你说话直接到有点扎人，但你看事情的准，大家都服。

**1. 朋友说：“要不周末去爬山吧？”**
- A “现在就去。”（原味焦香）
- B 提议换一条没开发过的野路线（开心果）
- C 什么都没带就出发了，路上缺什么买什么（抹茶）
- D 先查天气，发现周末下雨，直接改成今天（黑巧）

**2. 你在一个谁都不认识的聚会上**
- A 五分钟后在帮主人搬桌子，十分钟后在帮他点歌（原味焦香）
- B 提议大家玩一个刺激的游戏（开心果）
- C 有人冷场，你一句话就接住了（抹茶）
- D 已经看出来这群人里谁说了算（黑巧）

**3. 骑车到半路，导航突然没声音了** ← 反转题
- A 停下两秒，拿起手机三下搞定，继续走（原味焦香）
- B 干脆不导了，看看能骑到哪（开心果）
- C 凭感觉骑，反正大方向没错（抹茶）
- D 你本来就记得路，导航只是开着而已（黑巧）
- 反转：其实是你刚才不小心把手机调成了静音。

**4. 有人跟你说：“这个你肯定做不到。”**
- A 你已经开始做了（原味焦香）
- B 你不仅做了，还加大了难度（开心果）
- C 你当场想出一个他没想到的办法（抹茶）
- D 你算了一下，确实做不到，于是换了一个更聪明的方式赢他（黑巧）

**5. 凌晨两点，你在**
- A 刚从外面回来，今天的事还挺精彩（原味焦香）
- B 跟朋友临时决定去一个从没去过的地方（开心果）
- C 在一个突然开始的局里，玩得最开心的是你（抹茶）
- D 睡了，明天还有正事（黑巧）
